MediaPost Application - Complete Flow Documentation

1. Post Creation with Media Upload Flow

API Endpoint: POST /api/posts/upload

Flow Sequence: 1. Controller Layer (PostController.java:23-31) - Receives multipart form data: caption, file, userId - Calls postService.createPost()

  1. Service Layer (PostServiceImpl.java:34-49)
  2. Fetches user via userService.getById(userId)
  3. Uploads file via storageService.upload(file)
  4. Determines media type (video/image) based on content type
  5. Creates Post entity with caption, media URL, media type, and author
  6. Saves post to database via postRepository.save()

  7. Maps entity to DTO response

  8. Storage Layer (StorageServiceImpl.java:22-26)

  9. Generates unique filename with timestamp prefix
  10. Saves file to local filesystem

2. User Registration System

API Endpoint: POST /api/users/create

Flow Sequence: 1. Controller Layer (UserController.java:21-23) - Receives User entity in request body - Calls userService.createUser() - Returns HTTP 201 Created with saved user

  1. Service Layer (UserServiceImpl.java:22-23)
  2. Direct save to database via userRepository.save()

3. Comment System Implementation

API Endpoints: - POST /api/comments/add - Add comment - GET /api/comments/post/{postId} - Get comments by post

Add Comment Flow: 1. Controller Layer (CommentController.java:27-33) - Receives userId, postId, text as request parameters - Calls commentServiceImpl.addComment()

  1. Service Layer (CommentServiceImpl.java:28-37)
  2. Creates Comment entity with text, user reference, and post reference
  3. Saves comment via commentRepository.save()
  4. Increments post comment count via postService.incrementComment()

4. Like/Unlike Interaction System

API Endpoint: POST /api/Interactions/posts/{postId}/like

Flow Sequence: 1. Controller Layer (InteractionController.java:18-24) - Receives postId and userId as path variables - Calls interactionService.toggleLike()

  1. Service Layer (InteractionServiceImpl.java:25-38)
  2. Checks for existing like via interactionRepository.findByUserIdAndPostIdAndType()
  3. If like exists: Deletes interaction and decrements post like count
  4. If no like: Creates new Interaction entity, saves it, and increments post like count

5. Feed Retrieval System

API Endpoint: GET /api/posts/feed (implied from service method)

Flow Sequence: 1. Service Layer (PostServiceImpl.java:53-56) - Fetches paginated posts ordered by creation date descending - Maps each Post entity to PostResponseDTO

  1. DTO Transformation (PostServiceImpl.java:66-75)
  2. Uses ModelMapper for basic field mapping
  3. Constructs full media URL: "http://localhost:8080/media/" + post.getMediaUrl()
  4. Sets author name from post author's username

Key Technical Details

Counter Updates: - Like counts updated atomically in incrementLikes() and decrementLikes() - Comment counts updated in incrementComment() - All counter operations include safety checks (e.g., preventing negative like counts)

Media Handling: - Files stored with timestamp-based unique names - Media type determined from content type string - Static media serving from /media/* endpoint

Entity Relationships: - User → Post (one-to-many) - Post → Comment (one-to-many) - User → Post → Interaction (many-to-many through Interaction entity)

Error Handling: - Post not found throws RuntimeException - File empty validation in storage service - Basic validation for counter operations

Architecture Overview

The application follows standard Spring Boot architecture with clear separation of concerns across controller, service, and repository layers.

Technology Stack: - Spring Boot - Spring Data JPA - Spring Web (REST APIs) - ModelMapper for DTO mapping - Lombok for boilerplate reduction - Jakarta EE (formerly Java EE)

Database Operations: - All operations use JPA repositories - Transactional management with @Transactional - Entity references managed via EntityManager

API Design: - RESTful endpoints following HTTP standards - Proper HTTP status codes - Multipart support for file uploads - Pagination support for feed retrieval
